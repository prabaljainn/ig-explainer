# kubernetes-basics-hinglish script

## Narration
3 baje server crash hua. App down nahi hua. || रात 3 बजे server crash हुआ। App down नहीं हुआ।
Yehi hai Kubernetes. Apps chalti rehti hain. || यही है Kubernetes। Apps चलती रहती हैं।
Har box ek pod hai: aapka app, container mein. || हर box एक pod है: आपका app, container में।
Pods nodes par chalte hain. Node, bas ek machine. || Pods, nodes पर चलते हैं। Node, बस एक machine।
Kai nodes milkar ek cluster. || कई nodes मिलकर एक cluster।
Control plane dimaag hai. Aap batao kya chahiye. || Control plane दिमाग़ है। आप बताओ, क्या चाहिए।
Bolo 3 chahiye. Wo 3 pods start karta hai. || बोलो 3 चाहिए। वो 3 pods start करता है।
Ek pod mara? Notice karke naya start karta hai. || एक pod मरा? नोटिस करके नया start करता है।
Traffic badha? 3 ko 10 karo. 7 aur add. || Traffic बढ़ा? 3 को 10 करो। 7 और add।
Service inhe ek stable address deti hai. || Service, इन्हें एक stable address देती है।
Bas batao kya chahiye. Kubernetes sambhalega. || [hi]बस बताओ क्या चाहिए। [en]Kubernetes [hi]संभालेगा।
